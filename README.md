# sysinfo

A lightweight Bash script for displaying Linux system information.

## Features

- Hostname
- Operating System
- Kernel
- Architecture
- Uptime
- CPU
- Memory
- Disk usage
- IP address

## Installation

Clone the repository:

```bash
git clone git@github.com:alirezasoleiman/sysinfo.git

cd sysinfo

sudo ./install.sh

sudo rm /usr/local/bin/sysinfo
